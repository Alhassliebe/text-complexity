# Text Analysis with Authors_conllu

Этот проект предназначен для анализа текстов в формате `.conllu` и получения различных метрик. Результаты сохраняются в папку `outputs`.

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Подготовка данных

Загрузите папку с текстами Authors_conllu в директорию data/.

При необходимости, измените путь к данным в функции main() на нужную директорию.

## Использование

В функции main() доступны два режима обработки:

1. Обработка всех файлов в папке.
2. Обработка только первого файла (для демонстрации).

Закомментируйте или раскомментируйте нужный блок кода в main() для выбора режима.

## Результаты

Все метрики сохраняются в папку outputs/ после завершения работы скрипта.

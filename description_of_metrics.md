# Описание метрик сложности текста

## Синтаксические метрики

### 1. Средняя длина предложения (ASL)
**Формула:** Общее количество слов / Количество предложений
**Интерпретация:** Более длинные предложения обычно сложнее для восприятия. Значения выше 20 слов считаются сложными для понимания.

### 2. Глубина дерева зависимостей
**Формула:** Максимальная длина пути от корня до листа в синтаксическом дереве
**Интерпретация:** Отражает уровень вложенности синтаксических конструкций. Чем глубже дерево, тем сложнее структура предложения.

### 3. Средняя зависимостная дистанция (ADD)
**Формула:** Среднее расстояние между словом и его синтаксической головой
**Интерпретация:** Большие расстояния между зависимыми словами усложняют понимание текста.

### 4. Подчинительные конструкции на предложение
**Формула:** Количество зависимостей типа advcl, acl, ccomp, xcomp / Количество предложений
**Интерпретация:** Показывает насыщенность текста сложными синтаксическими конструкциями.

### 5. Сочинительные конструкции на предложение
**Формула:** Количество зависимостей типа conj, cc / Количество предложений
**Интерпретация:** Отражает использование сложносочиненных предложений.

## Лексические метрики

### 6. Лексическое разнообразие (TTR)
**Формула:** Количество уникальных слов / Общее количество слов
**Интерпретация:** Показывает богатство словарного запаса. Высокие значения (>0.7) указывают на разнообразную лексику.

### 7. Лексическая плотность
**Формула:** Количество знаменательных слов / Общее количество слов
**Интерпретация:** Отражает информационную насыщенность текста. Значения >0.6 характерны для научных текстов.

### 8. Доля Hapax Legomena
**Формула:** Количество слов, встречающихся один раз / Общее количество уникальных слов
**Интерпретация:** Высокие значения указывают на использование редких или специализированных слов.

### 9. Средняя длина слова
**Формула:** Среднее количество символов в слове
**Интерпретация:** Более длинные слова обычно сложнее для восприятия.

### 10. Среднее количество слогов в слове
**Формула:** Среднее количество гласных в слове (приближение для русского)
**Интерпретация:** Многосложные слова увеличивают сложность чтения.

## Морфологические метрики

### 11. Морфологическая сложность
**Формула:** Среднее количество морфологических признаков на слово
**Интерпретация:** Отражает грамматическую насыщенность текста.

### 12. Доля страдательного залога
**Формула:** Количество глаголов в страдательном залоге / Общее количество глаголов
**Интерпретация:** Высокие значения характерны для формального стиля и могут усложнять понимание.

### 13. Доля личных местоимений
**Формула:** Количество личных местоимений / Общее количество слов
**Интерпретация:** Высокие значения указывают на менее формальный стиль.

## Стилистические метрики

### 14. Количество частей речи на предложение
- **Глаголы:** Отражает динамичность текста
- **Прилагательные:** Показывает описательность
- **Существительные:** Указывает на информационную плотность

### 15. Модификаторы на существительное
**Формула:** Количество определений и приложений / Количество существительных
**Интерпретация:** Показывает сложность именных групп.

### 16. Знаки препинания на предложение
**Формула:** Количество знаков препинания / Количество предложений
**Интерпретация:** Отражает синтаксическую сложность предложений.

### 17. Дискурсивные маркеры на предложение
**Формула:** Количество связующих слов и выражений / Количество предложений
**Интерпретация:** Показывает логическую связность текста.

## Интегральные метрики

### 18. Индекс читаемости Флеша (русская версия)
**Формула:** 206.835 - 1.52×ASL - 65.14×ASW
где ASL = средняя длина предложения, ASW = среднее количество слогов в слове
**Интерпретация:** 
- 90-100: Очень легкий текст
- 70-89: Легкий
- 50-69: Средний
- 30-49: Сложный
- 0-29: Очень сложный

## Нормативные значения для русского языка

| Стиль текста | ASL | TTR | Индекс Флеша |
|-------------|-----|-----|--------------|
| Художественная литература | 8-15 | 0.6-0.8 | 50-70 |
| Научные тексты | 15-25 | 0.4-0.6 | 30-50 |
| Публицистика | 10-18 | 0.5-0.7 | 40-60 |
| Разговорная речь | 5-12 | 0.3-0.5 | 60-80 |
